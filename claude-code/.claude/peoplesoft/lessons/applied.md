# 教訓歸檔（applied）——本機帳本

> `/ps-lesson` 直接套用的教訓逐筆記錄於此（症狀／根因／落點／實際修改摘要／測試檢查點）。
> 本機套用即生效（開新的 Claude Code session 後）；**團隊生效以內部 git PR merge 為準**（SOP-1）。
> 本檔是歷史紀錄，**不載入任何 agent 的 context**。
> 編號用 `C<流水號>`（C1、C2…）：框架維護端的主帳本以 L 編號另計，兩者不混用；
> 回報維護端時講 C 編號與一句症狀即可（不貼路徑、物件名）。

## 登錄格式（縮排呈現；寫入時勿用三反引號圍欄）

    ### C<流水號> <一句話標題>（YYYY-MM-DD）
    - 症狀：模型做了什麼錯事
    - 根因：為什麼會犯（不確定寫「待補」）
    - 落點：機械化檢查 / 資料修正（哪個檔）/ 窄規則（哪個 agent 或 skill）/ CLAUDE.md
    - 實際修改摘要：改了哪個檔、加了哪一句（只加不刪）
    - 測試檢查點：怎麼重現、怎樣算修好
