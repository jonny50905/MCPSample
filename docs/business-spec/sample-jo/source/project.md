# 專案輸入

## 業務名稱

職缺管理（示範）

## 本期目標

- 用人主管與招募人員在系統上建立職缺並送審，取代紙本職缺申請單的簽核。
- 職缺依開缺人數走一層或兩層核准，核准後立即開放徵才。
- 招募人員可暫停、恢復、關閉職缺；已錄取人數達到開缺人數時，職缺自動標示為補足。
- 送審、退回、核准、補足時，相關人員收到通知。

## 補充說明（業務規則、範圍、例外，寫業務語言；不寫人名）

- 本期不含對外招募網站：職缺核准後不自動刊登到公司徵才網站，刊登仍由招募人員人工處理。
- 本期不含面試排程：面試時間的安排沿用現行做法，不在本系統處理。
- 本期不含應徵者管理與錄用作業；「已錄取人數」由現有的錄用作業回寫。
- 職位、部門、工作地點與主管關係以人事資料為準，不在職缺功能內維護。
- 職缺編號由系統給號，不沿用紙本申請單的編號。
- 舊有的紙本職缺申請單不轉入系統。
