# 2 Spec 是什麼

## 2.1 唯一業務真相
來源 Spec 是本期唯一的業務真相。本文件每條需求都要能指回來源 Spec 的位置。
來源 Spec 沒寫的業務行為，本文件不補，也不用舊系統（例如 PeopleSoft）或業界的一般做法推定。
來源 Spec 有缺漏、矛盾、未完成或看不懂之處，一律登記為假設（見第 7 章），交業務窗口或 Spec 產製端確認。
假設依業務窗口的回覆或 Spec 產製端補查後的新版關閉（見第 7 章 7.4）；業務窗口的回覆視為來源 Spec 的補充。
每條需求都要有證據：證據編號對到第 10 章，該章逐字摘錄來源原文。
本文件不修改來源 Spec。
