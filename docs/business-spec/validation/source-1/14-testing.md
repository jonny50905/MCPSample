# 14 測試

文件：TR-SPEC-14｜版本 0.9｜狀態：已審閱

## 1. 測試環境與自動化

- 測試環境以模擬的人事資料服務回應直屬主管。
- API 自動化測試覆蓋率目標 80%。

## 2. 驗收情境

| 編號 | 情境 | 預期結果 |
|---|---|---|
| UAT-01 | 員工報名尚有名額的梯次並送出 | 狀態為「已送出」；直屬主管的待審核清單出現此筆 |
| UAT-02 | 梯次名額已滿時，員工開啟報名單 | 只出現「登記候補」按鈕；登記後狀態為「候補」 |
| UAT-03 | 主管按「退回」但未填審核意見 | 顯示「退回時請填寫審核意見。」，報名維持「已送出」 |
| UAT-04 | 訓練承辦確認一筆「主管核准」的報名 | 狀態為「已確認」 |

## 3. 效能測試

- 模擬 200 人同時報名同一梯次的最後 1 個名額，計入名額人數不得超過名額。
