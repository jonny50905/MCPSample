# 09 業務規則與訊息

文件：TR-SPEC-09｜版本 0.9｜狀態：已審閱（§5 草稿）

## 1. 報名

- BR-01 報名須於報名截止日前送出；逾期不受理，顯示 TR-E-002。
- BR-02 同一員工對同一課程，同一時間只能有一筆有效報名（已送出、候補、主管核准、已確認）。違反時顯示 TR-E-003。
- BR-03 名額計算：狀態為已送出、主管核准、已確認的報名計入名額；候補不計入。計入人數達名額時，不可再送出，只能登記候補。
- BR-04 送出時須再檢查一次名額，避免多人同時報名最後名額而超過名額。作法：送出時以資料庫交易鎖定該梯次資料列（SELECT … FOR UPDATE）後計數，計數與寫入報名於同一交易內完成；超過時顯示 TR-E-004。
- BR-05 審核者為送出當時人事資料中的直屬主管。

## 2. 審核與確認

- BR-06 主管退回時，審核意見必填；未填顯示 TR-E-005。
- BR-07 訓練承辦只能確認狀態為「主管核准」的報名。

## 3. 取消

- BR-08 主管核准前，員工可自行取消本人的報名。
- BR-09 主管核准後至開課日前一日（含），員工可自行取消報名；取消後名額即釋出。
- BR-10 開課日當天起，任何人都不可取消報名，顯示 TR-E-006；未到課者由訓練承辦登錄缺席。
- BR-11 訓練承辦取消梯次時，該梯次所有尚未結束的報名改為「已取消」。

## 4. 梯次維護

- BR-12 報名截止日不得晚於上課開始日；違反時顯示 TR-E-007。
- BR-13 名額不得調降至低於目前計入名額的人數；違反時顯示 TR-E-008。
- BR-14 梯次開課前 3 日，符合條件者由系統自動處理。

## 5. 完訓與缺席判定（草稿）

- BR-15 出席時數達課程時數 80% 以上者登錄為完訓；未達者登錄為缺席。
- BR-16 缺席者自該梯次結束日起半年內，不得再報名同一課程。
