# 06 系統架構

文件：TR-SPEC-06｜版本 0.9｜狀態：已審閱

## 1. 架構概觀

- 三層架構：瀏覽器前端 → 應用服務（REST）→ 關聯式資料庫。
- 前端為單頁應用，以 JSON 與應用服務溝通。
- 應用服務無狀態，可水平擴充；以權杖（token）驗證使用者。

## 2. 模組

tr-web（前端畫面）、tr-api（報名、審核、確認、出席 API）、tr-batch（排程作業）、tr-hr-adapter（呼叫人事資料服務）、tr-notify-adapter（呼叫郵件通知服務）。

## 3. 非功能需求

| 項目 | 要求 |
|---|---|
| 回應時間 | 查詢 95% 於 2 秒內完成 |
| 應用程式日誌 | 記錄所有 API 呼叫，保留 90 天 |
| 部署 | 測試、正式兩套環境；以容器映像發布 |
