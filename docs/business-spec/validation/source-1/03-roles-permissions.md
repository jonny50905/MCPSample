# 03 角色與權限

文件：TR-SPEC-03｜版本 0.9｜狀態：已審閱

## 1. 角色

| 角色 | 說明 | 系統角色代碼 |
|---|---|---|
| 員工 | 所有在職員工，即報名者 | TR_EMP |
| 直屬主管 | 報名者在人事資料中的直屬主管 | TR_MGR |
| 訓練承辦 | 人資部門指派的承辦人員 | TR_ADMIN |

## 2. 功能權限

| 功能 | 員工 | 直屬主管 | 訓練承辦 |
|---|---|---|---|
| 查詢開放報名的梯次 | ✓ | ✓ | ✓ |
| 報名／登記候補（本人） | ✓ | ✓ | ✓ |
| 取消報名（主管核准前） | ✓（限本人） | ✗ | ✓ |
| 取消報名（主管核准後） | ✗ | ✗ | ✓ |
| 核准／退回 | ✗ | ✓（限直屬部屬） | ✗ |
| 確認報名 | ✗ | ✗ | ✓ |
| 登錄出席結果 | ✗ | ✗ | ✓ |
| 課程與梯次維護、取消梯次 | ✗ | ✗ | ✓ |

註：主管本人報名時，由其本人的直屬主管審核。

## 3. 資料範圍

| 角色 | 可看到的報名資料 |
|---|---|
| 員工 | 本人的報名 |
| 直屬主管 | 本人與直屬部屬的報名（不含部屬的部屬） |
| 訓練承辦 | 全部報名 |

## 4. 角色指派

- 角色由系統管理員於現有權限管理功能指派，不在本功能範圍。
- 每支 API 於伺服器端檢查呼叫者角色（見 08 §2）。
