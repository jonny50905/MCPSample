# 業務需求文件撰寫規範：試寫驗證

`../standard.md` 經三輪試寫驗證。每輪 3 個 Sonnet 各自獨立照規範寫（只讀規範與來源，不看答案與彼此的產出），
再由一個沒參與起草的模型（第一、三輪 Fable，第二輪 Opus）以答案卷比對。來源全部是合成的，不含任何真實公司或系統內容。

- 第三輪覆核建議的最後修正已套進 `../standard.md`（未再重跑；覆核估算來源 2 第一份的待確認會由 23% 降到約 17%）。

## 怎麼重跑

1. 準備空的輸出資料夾，把 `source-1/` 或 `source-2/` 複製一份當 `<來源資料夾>`。
2. 開一個 Sonnet session，輸入 `../README.md`「怎麼用」第 4 步那句；試寫時另請它在輸出資料夾寫 `trial-notes.md`（猶豫點，40 行內）。
3. 用對應的答案卷比對：埋的問題命中、評分表、假設筆數、待確認占比、驗收情境條數。
