## 2 範圍

### 2.1 本期包含

| 項次 | 功能 | 說明 |
|---|---|---|
| 1 | 證明申請 | 員工線上填寫證明申請單並送出，可先儲存草稿 |
| 2 | 代理申請 | 員工替同部門員工提出申請 |
| 3 | 急件核准 | 急件由申請人的直屬主管核准 |
| 4 | 人資審核 | 人資承辦審核通過、退回補正或不予核發 |
| 5 | 製發與領取 | 人資承辦登錄用印完成與領取；逾期未領取者作廢 |
| 6 | 撤回 | 申請人或代理人於製發前撤回申請 |
| 7 | 申請查詢 | 員工查詢本人或本人代理的申請；人資查詢全部申請 |

| 項次 | 項目 | 說明 |

| 3 | 印信管理 | 用印依總務單位既有的印信管理程序辦理，本系統只登錄用印完成 |
| 4 | 角色指派 | 人資承辦、人資主管由既有的權限管理功能指派，不在本功能範圍 |

|---|---|---|
| 1 | 電子簽章版證明 | 線上下載附電子簽章的證明檔，本期不做；證明一律紙本用印 |

## 3 角色

### 3.1 角色定義

| 角色 | 說明 |
|---|---|
| 申請人 | 需要證明的員工本人；代理申請時指被代理的員工 |
| 代理人 | 替同部門員工提出申請的在職員工，不需事先指定 |
| 直屬主管 | 人事資料中申請人的直屬主管；只參與急件核准 |
| 人資承辦 | 人資單位負責證明業務的人員 |
| 人資主管 | 人資單位主管；接收逾期未製發通知 |

### 3.2 權限

| 功能 | 申請人 | 代理人 | 直屬主管 | 人資承辦 | 人資主管 |
|---|---|---|---|---|---|
| 填寫、儲存草稿、送出申請單 | ✓ | ✓ | ✗ | ✗ | ✗ |
| 撤回申請 | ✓ | ✓ | ✗ | ✗ | ✗ |
| 急件核准、退回 | ✗ | ✗ | ✓ | ✗ | ✗ |
| 人資審核（審核通過、退回、不予核發） | ✗ | ✗ | ✗ | ✓ | ✗ |
| 登錄用印完成、登錄領取 | ✗ | ✗ | ✗ | ✓ | ✗ |
| 查詢申請 | ✓ | ✓ | ✓ | ✓ | ✓ |

查詢範圍：申請人看本人的申請（含他人替本人代理的申請）；代理人看本人代理的申請；直屬主管看直屬部屬的急件申請；人資承辦、人資主管看全部申請。人資主管只能查詢，不能修改。

## 4 流程

### 4.1 主要流程

1. 申請人開啟「證明申請單」，系統自人事資料帶入申請人資料（見 8.1）。
2. 申請人選擇證明種類、語言版本、份數與領取地點，填妥申請單後送出。
3. 申請單轉為「待審核」，系統通知人資承辦（見 8.2），由人資承辦審核。選急件時，改為先轉「主管核准中」送申請人的直屬主管核准，並通知直屬主管；直屬主管核准後才轉為「待審核」，由人資承辦審核。
4. 人資承辦審核通過後，申請單轉為「製發中」。人資承辦列印證明、依印信管理程序用印後，在系統登錄用印完成，申請單轉為「待領取」，系統通知申請人領取（見 8.2）。
5. 領取人至領取地點領取，人資承辦核對領取人身分後登錄領取，申請單轉為「已領取」，流程結束。

### 4.2 退回補正

- 人資承辦審核時（4.1 第 3 步）認為資料需修正，可按「退回」並填寫退回原因；直屬主管核准急件時也可退回並填寫退回原因。申請單轉為「退回補正」，系統通知申請人。
- 申請人修改後重新送出，回到 4.1 第 3 步；重新送出的次數不限。
- 補正期限為退回日之次一工作天起算 5 個工作天（退回當日不計）。補正期限屆滿仍未重新送出者，申請單自動撤回（見 5.1）。

### 4.3 不予核發

人資承辦審核時，申請人不符申請資格（例：在職狀態不符所申請的證明種類），可選「不予核發」並填寫原因；申請單轉為「不予核發」，流程結束，系統通知申請人。

### 4.4 撤回

申請人或代理人於申請單為「主管核准中」「待審核」「退回補正」時可撤回，撤回前須再確認一次；撤回後申請單轉為「已撤回」，流程結束。申請單進入「製發中」後不得撤回。

### 4.5 代理申請

代理人開啟「證明申請單」，申請對象選「代理同部門員工」並選定被代理員工後，依 4.1 第 1～2 步代為填寫並送出，之後同 4.1 第 3 步起。送出時系統另通知被代理員工（見 8.2）。

### 4.6 逾期未領取

證明製發完成後，申請人應於領取期限內領取。超過領取期限仍未領取者，申請單轉為「逾期作廢」，人資承辦將該份證明銷毀。申請人如仍需要證明，須重新申請。

## 5 狀態

### 5.1 狀態清單

| 狀態 | 說明 | 進入方式 |
|---|---|---|
| 草稿 | 申請單已建立、尚未送出 | 新增申請單（送出前皆為草稿） |
| 主管核准中 | 急件等待直屬主管核准 | 急件送出 |
| 待審核 | 等待人資承辦審核 | 一般件送出；急件經直屬主管核准 |
| 退回補正 | 退回申請人修正 | 直屬主管或人資承辦退回 |
| 製發中 | 人資承辦審核通過，列印與用印中 | 人資承辦審核通過 |
| 待領取 | 證明已用印完成，等待領取 | 人資承辦登錄用印完成 |
| 已領取 | 證明已領取，結案 | 人資承辦登錄領取 |
| 逾期作廢 | 超過領取期限未領取，證明作廢 | 領取期限屆滿時由系統自動轉換 |
| 不予核發 | 人資承辦審核不予核發，結案 | 人資承辦選不予核發 |
| 已撤回 | 申請已撤回，結案 | 申請人或代理人撤回；補正期限屆滿時由系統自動轉換 |

「已領取」「逾期作廢」「不予核發」「已撤回」為終止狀態，之後不得再變更。

### 5.2 狀態轉移

| 從 | 到 | 觸發者 | 條件 |
|---|---|---|---|
| 草稿 | 待審核 | 申請人、代理人 | 一般件送出 |
| 草稿 | 主管核准中 | 申請人、代理人 | 急件送出 |
| 主管核准中 | 待審核 | 直屬主管 | 核准 |
| 主管核准中 | 退回補正 | 直屬主管 | 退回，須填退回原因 |
| 待審核 | 製發中 | 人資承辦 | 審核通過 |
| 待審核 | 退回補正 | 人資承辦 | 退回，須填退回原因 |
| 待審核 | 不予核發 | 人資承辦 | 須填不予核發原因 |
| 退回補正 | 待審核 | 申請人、代理人 | 一般件重新送出 |
| 退回補正 | 主管核准中 | 申請人、代理人 | 急件重新送出 |
| 主管核准中、待審核、退回補正 | 已撤回 | 申請人、代理人 | 撤回 |
| 製發中 | 待領取 | 人資承辦 | 登錄用印完成 |
| 待領取 | 已領取 | 人資承辦 | 登錄領取 |
| 待領取 | 逾期作廢 | 系統 | 超過領取期限未領取 |

備註：「製發中」「待領取」的申請單不得撤回。

## 6 畫面描述

### 6.1 我的申請

申請人、代理人用來查詢本人的申請與本人代理的申請。清單依申請日由新到舊排序。按「新增申請」開啟空白的證明申請單；「撤回」按鈕在申請單送出後顯示，可否撤回依 4.4。

### 6.2 證明申請單

申請人或代理人用來填寫、儲存草稿與送出申請。開啟時帶入人事資料。「申請對象」選「代理同部門員工」時出現「被代理員工」欄，選定後改帶入被代理員工的人事資料。領取地點以下拉選單選擇。勾選「急件」時出現「急件原因」。送出後畫面轉為唯讀，申請單為「退回補正」時再開放修改。

### 6.3 急件核准

直屬主管用來核准或退回直屬部屬的急件申請。清單只列狀態為「主管核准中」、且直屬主管為登入者的申請，依申請日由舊到新排序。退回時須填「主管意見」，作為退回原因。

### 6.4 人資作業

人資承辦用來審核、登錄用印完成與登錄領取；人資主管只能查詢。清單預設只顯示「待審核」的申請；急件排在一般件之前，同類依申請日由舊到新排序。超過製發期限的申請顯示「逾期未製發」標示（見 7.2）；通知寄送失敗的申請顯示「通知失敗」標示（見 8.2）。

## 7 業務規則

### 7.1 申請與急件

| 編號 | 規則 |
|---|---|
| R-01 | 每種證明每次申請 1～3 份；送出時份數超過上限者不得送出，顯示 E-001。 |
| R-02 | 同一員工同一證明種類，在「主管核准中」「待審核」「退回補正」「製發中」「待領取」中只能有一筆申請；送出時檢核，違反時顯示 E-002。 |
| R-03 | 在職狀態不是「在職」者不得申請在職證明，送出時檢核，違反時顯示 E-003；服務證明不受此限。 |
| R-04 | 代理人只能替同部門的在職員工申請；選定被代理員工時檢核，違反時顯示 E-004。 |
| R-05 | 申請單號於送出時以 UUID 產生，送出後顯示於證明申請單與「我的申請」。 |
| R-06 | 外派人員及特殊身分者之證明申請，依專案辦理。 |
| R-07 | 勾選急件時須填寫急件原因；送出時未填者顯示 E-005。 |
| R-08 | 每位申請人每月急件以 2 次為限，以申請日所在月份計算，已撤回的急件不計入；超過時不得以急件送出，顯示 E-006。 |
| R-09 | 急件須經申請人的直屬主管核准後，才由人資承辦審核（見 4.1 第 3 步）。 |

### 7.2 製發期限

| 編號 | 規則 |
|---|---|
| R-10 | 一般件應自申請日起 5 個工作天內製發完成（登錄用印完成）。 |
| R-11 | 急件應自直屬主管核准日起 2 個工作天內製發完成。 |
| R-12 | 申請單的「預計製發日」依 R-10、R-11 計算，申請單轉為「待審核」時顯示。 |
| R-13 | 超過製發期限仍未登錄用印完成者，由排程每 10 分鐘掃描，於人資作業清單標示「逾期未製發」，並通知人資主管（見 8.2）。 |

### 7.3 領取與逾期

| 編號 | 規則 |
|---|---|
| R-14 | 人資承辦登錄領取前，須核對領取人身分；登錄時須填寫領取人姓名與領取日期，未填者顯示 E-012。 |
| R-15 | 超過領取期限未領取者，由系統轉為「逾期作廢」（見 4.6）；作廢的證明由人資承辦銷毀。 |
| R-16 | 補正期限屆滿仍未重新送出者，由系統將申請單轉為「已撤回」，並通知申請人（見 8.2）。 |

### 7.4 語言版本（草稿）

| 編號 | 規則 |
|---|---|
| R-17 | 語言版本選「英文」時，「英文姓名」必填，預設帶入人事資料的英文姓名，可修改；送出時未填者顯示 E-011。 |
| R-18 | 英文版證明的製發期限，較 R-10、R-11 各加 2 個工作天。 |
| R-19 | 英文版服務證明只記載最近一個職稱，不列歷任職務。 |

## 8 外部介面

### 8.1 人事資料

| 項目 | 內容 |
|---|---|
| 對象 | 人事資料 |
| 內容 | 員工編號、姓名、英文姓名、部門、職稱、到職日、在職狀態、直屬主管 |
| 時機 | 開啟證明申請單時；選定被代理員工時；人資承辦按「審核通過」前再取一次在職狀態 |
| 用途 | 帶入申請單；在職狀態用於 R-03 與人資審核；部門用於 R-04；直屬主管用於急件核准 |
| 連線設定 | 見 9.2 |

### 8.2 通知

| 事件 | 收件人 | 內容 |
|---|---|---|
| 一般件送出；急件經直屬主管核准 | 人資承辦 | 有新的證明申請待審核：申請單號、申請人、證明種類、是否急件 |
| 急件送出 | 直屬主管 | 有急件待核准：申請單號、申請人、證明種類、急件原因 |
| 代理申請送出 | 被代理員工 | 他人已代為申請：申請單號、代理人、證明種類 |
| 退回補正 | 申請人；代理申請時另通知代理人 | 退回原因、補正期限 |
| 不予核發 | 申請人；代理申請時另通知代理人 | 不予核發原因 |
| 登錄用印完成 | 申請人；代理申請時另通知代理人 | 「您申請的證明已製發完成，請於領取期限前至領取地點領取。」、領取地點、領取期限 |
| 逾期未製發 | 人資主管 | 申請單號、申請人、預計製發日 |
| 補正期限屆滿自動撤回 | 申請人 | 申請單號、撤回原因「補正期限屆滿」 |

通知寄送失敗不影響申請單狀態；人資作業清單中該筆申請顯示「通知失敗」，由人資承辦以電話通知收件人。

## 10 驗收情境

| 編號 | 情境 | 前置條件 | 步驟 | 預期結果 |
|---|---|---|---|---|
| AT-01 | 一般件申請到領取 | 申請人在職狀態為「在職」，無處理中的在職證明申請 | 1. 申請人新增申請，選在職證明、中文、1 份，填妥申請單後送出 2. 人資承辦審核通過 3. 人資承辦登錄用印完成 4. 人資承辦登錄領取 | 送出後顯示「申請已送出。」；狀態依序為「待審核」「製發中」「待領取」「已領取」；登錄用印完成後申請人收到領取通知 |
| AT-02 | 份數超過上限 | 無 | 申請人申請服務證明 6 份並送出 | 顯示「申請份數超過上限。」，無法送出 |
| AT-03 | 急件經直屬主管核准 | 申請人本月尚未申請急件 | 1. 申請人勾選急件、填寫急件原因後送出 2. 直屬主管在急件核准畫面按「核准」 | 送出後狀態為「主管核准中」，直屬主管收到通知；核准後狀態為「待審核」，人資承辦收到通知 |
| AT-04 | 退回補正後重新送出 | 申請單為「待審核」 | 1. 人資承辦未填審核意見即按「退回」 2. 填寫審核意見後按「退回」 3. 申請人修改後重新送出 | 第 1 步顯示「退回時請填寫退回原因。」；第 2 步後狀態為「退回補正」，申請人收到通知；第 3 步後狀態為「待審核」 |
| AT-05 | 製發中不可撤回 | 申請單為「製發中」 | 申請人在我的申請按「撤回」並確認 | 顯示「證明已進入製發，無法撤回。」，狀態不變 |
| AT-06 | 補正期限屆滿自動撤回 | 申請單為「退回補正」 | 申請人在補正期限內未重新送出 | 補正期限屆滿後，申請單狀態為「已撤回」，申請人收到撤回通知 |
