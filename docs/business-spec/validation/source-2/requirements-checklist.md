# 員工證明文件申請 需求驗收清單

對應主規格 v0.8。業務驗收時逐項確認，通過者打勾。

## 1 申請

- [ ] RC-01 員工可線上申請在職證明與服務證明，並可先儲存草稿。
- [ ] RC-02 每種證明每次申請的份數不得超過上限，超過時不能送出。
- [ ] RC-03 同一種證明尚在處理中時，不能再申請同一種證明。
- [ ] RC-04 在職狀態不是「在職」的員工不能申請在職證明，但可以申請服務證明。
- [ ] RC-05 代理人只能替同部門的在職員工申請，送出後被代理員工會收到通知。

## 2 急件

- [ ] RC-06 急件須經申請人的直屬主管核准後，才進入人資審核。
- [ ] RC-07 急件申請要在 2 個工作天內製發。
- [ ] RC-08 每人每月急件最多 2 次，已撤回的急件不計入。

## 3 審核與製發

- [ ] RC-09 人資承辦退回或不予核發時一定要填原因。
- [ ] RC-10 退回後申請人可修改再送出；補正期限內未送出的申請會自動撤回。
- [ ] RC-11 超過製發期限仍未製發的申請，人資主管會收到通知。

## 4 領取

- [ ] RC-12 證明製發完成後，申請人會收到領取通知。
- [ ] RC-13 逾期未領取的證明要作廢。
- [ ] RC-14 證明遺失時可申請補發，補發不計入份數上限。

## 5 撤回

- [ ] RC-15 申請進入製發後不能撤回。
